# Keep Score on GitHub

The official watch release is **0.23.11 (50)**. Its public source includes the round-display controls, tappable menu paths and the illustrated watch menu guide. Published app and website changes are mirrored together in the [GitHub review branch](https://github.com/andrew01ait/squash-tap/pull/1). The same source is available as a [ZIP download](https://squash-tap-andrew.endruuu.chatgpt.site/KeepScore-source.zip).

## Finding the source

The watch application and its tests are in `android/`. The phone, tablet and audience pages are in `public/`. The [navigation guide](FLOW.md) describes the routes for scorers, referees and following watches. The [rules](RULES.md) cover the six supported sports.

For a local build, see [building Keep Score](DEPLOYMENT.md) and [test coverage](TESTING.md). To install an official watch update, use the [download page](https://squash-tap-andrew.endruuu.chatgpt.site/).
