# Keep Score distribution

The current public watch release is **v0.20.1 / code 28**. Install it from the [official download page](https://squash-tap-andrew.endruuu.chatgpt.site/) or open Settings → Check for updates on a watch that already has the direct version.

The project also has a separate Google Play preparation build. The published APK and all watch navigation described in the [installation guide](INSTALLATION.md) use the direct distribution channel. A Google Play release will be announced separately.

See the [changelog](CHANGELOG.md) for release features and the [versioning guide](VERSIONING.md) for the distinction between direct and preparation builds.
